Лабораторна робота: UI елементи та їх призначення

Демонстрація 10 основних користувацьких інтерфейсів (UI елементів) з інтерактивними прикладами та їх призначенням.

Дія виконана!
1

Radiobutton (Радіокнопка)

Призначення: Дозволяє користувачеві обрати лише один варіант із декількох взаємовиключних опцій у групі.
2

Checkbox (Прапорець / Чекбокс)

Призначення: Використовується для вибору одного або кількох варіантів незалежно один від одного, або для ввімкнення/вимкнення конкретного стану (on/off).
3

Text input (Текстове поле)

Призначення: Служить для введення користувачем однорядкового тексту (імені, email, пошукового запиту тощо).

Введено: ...

4

Tabs (Вкладки)

Призначення: Дозволяє перемикатися між різними розділами контенту в межах одного й того ж екранного простору, економлячи місце.
Це картка товару. Тут відображається загальний опис та основна інформація.
Матеріал: Пластик/Метал
Вага: 250г
Гарантія: 12 місяців
5

Button (Кнопка)

Призначення: Використовується для ініціації дії при натисканні (відправка форми, відкриття модального вікна, збереження даних тощо).
6

Text label (Текстова мітка)

Призначення: Для відображення статичного тексту або пояснювального напису поруч із полем введення або іншим контролом для забезпечення зрозумілості.
7

Link (Гіперпосилання)

Призначення: Забезпечує навігацію на іншу сторінку, інший розділ документа або зовнішній веб-ресурс.

Перейдіть на Вікіпедію (Інтерфейс користувача) щоб дізнатися більше.

8

Tooltip (Спливаюча підказка)

Призначення: Відображає додаткову довідкову інформацію при наведенні курсору миші на елемент (або при фокусі).
Це підказка з додатковою інформацією!
9

Dropdown list (Випадаючий список)

Призначення: Дозволяє користувачеві обрати одне значення з розгортаємого списку, заощаджуючи простір екрану.
10

Data grid (Таблиця даних)

Призначення: Відображення структурованих даних у вигляді рядків та стовпчиків із можливістю зручного перегляду, а часто й сортування або фільтрації.
